# 🚀 n8n Crypto Alert Pipeline

## 📌 Overview
This project uses n8n to monitor cryptocurrency market data via API, detect significant price movements, and automatically send alerts.

## ⚡ Features
- Automated data fetching every 15 minutes
- Real-time crypto data via API
- Rule-based alert system (price change detection)
- Data logging for further analysis

## 🛠 Tech Stack
- n8n (workflow automation)
- HTTP APIs (crypto data)
- Docker
- Telegram / Email alerts

## 🧠 Use Case
This workflow simulates a real-world data pipeline:
- Fetch market data
- Process and filter relevant information
- Trigger alerts based on conditions
- Store results for tracking and analysis
